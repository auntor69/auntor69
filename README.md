# Auntor

Dhaka, Bangladesh · building as **Afterclass Studio**

## Projects

**[টাইপ করি · Type Kori](https://github.com/auntor69/type-kori)**
The Bangla typing trainer — 12 structured lessons, endless speed tests, 261 contrast-checked themes, weak-key drills, and a command bar. No sign-up; your progress stays on your device. → [typekori.vercel.app](https://typekori.vercel.app)

`Astro` `Preact` `TypeScript` `PWA`

**[জমির হিসাব · Jomi Hisheb](https://github.com/auntor69/jomi-hisheb)**

`React` `Vite` `TypeScript` `Vitest` `PWA`

**[The EWU Express](https://github.com/auntor69/theewuexpress)**
Campus media platform for East West University — social-style feed, full-text search, and an admin dashboard with a rich-text editor. → [theewuexpress.vercel.app](https://theewuexpress.vercel.app)

`Next.js` `Drizzle ORM` `libSQL / Turso` `NextAuth`
